# Visualizer v0.6.2

## Version Goal

数据面板精简、样式联动修复与画布交互优化。不加新功能面，只把 0.6.1 里不顺手和不正确的地方改对。

软件版本：`0.6.2`  
工程格式：`projectFormatVersion: "1.1"`（未改）  
文档结构：`schemaVersion: 2`（未升）  
模板格式：`templateFormatVersion: 1`

## 如何运行

用 Chrome 打开仓库根目录的 `temperature_trajectory_visualizer.html`。开发时也可在仓库根目录执行 `python3 -m http.server` 后访问该页。核心测试：`node tests/core-test.js`。

## 已完成

- 数据簇快速样式：颜色方式、配色、颜色、线型、线宽每改一项就立即生效，只写这一项，不重置其他项。拖一次线宽滑块只记一步撤销。「全部重新应用」保留，用来把面板上的完整样式重新写到该簇在当前图里的全部系列。
- 选中系列的样式只改当前图里选中的系列，不再顺带改数据簇里的源系列，也不影响其他图窗。
- 绘图模式视口：适应窗口、适应宽度、100% 用可见工作区计算，图窗四周留 24 px 边距；放大后左右上下都能平移到底；平移后再点适应窗口会重新居中；侧栏折叠 / 展开、浏览器缩放窗口、Dock 固定 / 自动隐藏后仍保持适应。不改图窗真实尺寸。
- 触控板捏合和 Ctrl / ⌘ + 滚轮：按滚动量连续指数缩放，单次最多约 ±22%，以指针下的图上位置为锚点，一帧合并一次。普通滚轮不拦截。工具栏 − / + 和快捷键按 10% 档位走。缩放百分比可以直接输入。
- 浮层：右键菜单在四个角都不出界，靠底边时向上翻；Dock「新建」弹层挂到页面最外层，不再被 Dock 行裁掉；紧凑 Dock 的「画布」和「新建」图标有悬停提示；吸附菜单、布局菜单、Dock 预览、数据簇概览用同一个定位函数。Esc 关闭右键菜单、Dock 弹层和数据簇概览。层级固定为 Dock < 提示 / 预览 < 弹层 < 右键菜单，对话框在浏览器顶层。
- 数据面板：「概览」只在数据簇标题上。系列行只剩复选框、颜色点、名称、淡色点数；单条系列信息放在悬停提示里。数据簇概览是可关闭的小弹层，实时显示来源文件、系列数、已选、已加入图窗（含当前图）、有效点、每条点数是否一致、X 列与范围、Y 单位、导入时间。

## 修复的问题与原因

| 问题 | 原因 |
| --- | --- |
| 簇样式线宽 / 线型要点别处才生效 | 颜色是实时写入，线型线宽只改面板草稿，要按按钮才写；按钮又把草稿里所有字段（含默认颜色）一起写回，还清掉全部单独覆盖 |
| 适应窗口偏移、贴右、平移不到边 | 用 flex 居中 + overflow 滚动，最大滚动位置没有尾部留白；缩放锚点计算忽略了居中偏移；程序滚动的保护标记在滚动事件到达前就被清掉，适应状态被误切成手动 |
| 浮层出界、被遮挡 | 右键菜单只夹左上；Dock「新建」弹层放在横向可滚动的 Dock 行里被裁；紧凑图标没有提示；各菜单各自算位置 |
| 系列行太挤 | 每行都有「概览」按钮和展开表 |
| 触控板捏合太灵敏 | 每个滚轮事件固定 ±10%，不看滚动量，捏合一下就连跳多档 |
