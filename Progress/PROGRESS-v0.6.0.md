# Visualizer v0.6.0

## Version Goal

把一张图和它在纸上的一次摆放分开：图窗可以单独编辑、单独导出，也能被多张画布引用。

软件版本：`0.6.0`  
工程格式：`projectFormatVersion: "1.1"`（仍读取 `1.0`）  
文档结构：`schemaVersion: 2`（未升）  
模板格式：`templateFormatVersion: 1`

## 如何运行

用 Chrome 打开仓库根目录的 `temperature_trajectory_visualizer.html`。开发时也可在仓库根目录执行 `python3 -m http.server` 后访问该页。核心测试：`node tests/core-test.js`。本机没有 Microsoft Edge。

## 已实现

- 新建工程有画布 1、图窗 1，以及图窗 1 在画布 1 上的一个实例。
- 底部 Dock 切换画布和图窗。新建可选图窗或画布。识别色按浅橙、浅绿、浅紫循环，不改变曲线配色。
- 排版模式改实例的位置和大小。双击图或点 Dock 进入绘图模式。绘图模式的纸面只含当前图窗。返回后位置还在。
- 排版模式可以框选多个实例。多选属性不一致时显示「混合值」，只覆盖改过的字段。可以对齐和等间距。有数据的 Dock 缩略图画出曲线。
- 同一图窗可放进多张画布。内容同步，位置和大小各自保存。
- 删除仍被引用的图窗时列出画布名称。从画布移除实例不删除图窗。
- 图窗 PNG / SVG 不含同一画布上的其他图。画布导出保留各实例的位置。
- 旧 `1.0` 工程打开后，原图变成图窗，原布局变成画布 1 上的实例。局部视图仍挂在父图上。
- 画布预设增加单栏 89 mm、双栏 183 mm。

## 已知限制

- 同一张画布不能放同一图窗的第二个实例。
- 系统文件保存框没有弹出。Playwright 拦截了 `showSaveFilePicker`。SVG 验证走的是下载回退。
- 没有用十余个图窗做压力测试。没有测 Edge。
- 空图窗的 Dock 缩略图仍是缩小后的空图。
