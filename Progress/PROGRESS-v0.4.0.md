# Visualizer v0.4.0

## Version Goal

图层、选中和局部视图分开。局部视图是来源主图的另一个视窗，不再复制一套系列样式。

软件版本：`0.4.0`（只改 `APP_INFO.version`）  
工程格式：`projectFormatVersion: "1.0"`（未升格式版本）  
文档结构：`schemaVersion: 2`

## 如何运行

仓库根目录用 Chrome 或 Edge 打开 `temperature_trajectory_visualizer.html`，同目录需要 `visualizer-core.js`。开发调试可执行 `python3 -m http.server`。核心测试：`node tests/core-test.js`。

## 已完成

- 选中、拖动和改属性不再改变图层。原因是旧界面把选中图设为 `z-index: 4`，并把节点挪到画布末尾，从而盖住局部视图和引导线。
- 每张图有稳定的 `zOrder`、`visible`、`locked`。右侧「图层」可选择、显示/隐藏、锁定，以及上移、下移、置顶、置底。被挡住的图可以从图层选中。选中框和缩放手柄在单独的 overlay 上，不进入 PNG / SVG。
- 局部视图通过 `detailSource.sourceFigureId` 读取来源主图的数据和系列样式。主图改颜色、线宽、线型或显隐后，局部视图下次绘制立即跟随。局部视图属性里没有系列样式编辑。
- 局部视图默认关闭图标题、轴标题和图例，打开后可以再显示。关闭标题或轴标题会收回对应边距。图层名称不依赖图标题。
- X/Y 视窗可手动设置。默认按当前 X 窗口里可见系列自动适配 Y，边距 5%。属性中显示按绘图区计算的有效放大倍率。
- 新建局部视图默认叠在来源主图之上。引导线使用同一层级，位于来源图之上、局部图之下。导出顺序与画布一致。
- 删除带局部视图的主图时会确认，并一起删除这些局部视图。旧工程缺新字段时补默认值；旧局部图里复制的系列样式在打开后不再使用。

## 兼容性

`v0.1.0`～`v0.3.2` 工程仍按格式 `1.0` 打开。缺 `schemaVersion`、`zOrder`、`showTitle`（轴）时由 loader 补上。已有图标题默认继续显示。

## 已知限制

- 图层列表还不能拖拽排序，只用四个按钮。
- 引导线仍是直线，不绕开中间的图。
- 锁定只挡住画布上的拖动和缩放，属性面板仍可改内容。
- 本轮核心行为由 `node tests/core-test.js` 覆盖。浏览器核对见本版 DEVLOG；没有另开系统 Chrome / Edge 做完整安装包回归。

## 下一步

停在 v0.4.0。不要接着做 Formula、MAE / RMSE、Results、双 Y 轴、Heatmap、3D、图拆分或桌面打包。若要补图层拖拽排序，应使用 Pointer Events，并且不能在拖拽过程中改写选中状态以外的绘制。
