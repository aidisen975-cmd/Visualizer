# Visualizer v0.3.2

## Version Goal

在 v0.3.1 上补齐已经存在、但交互还不完整的科研绘图基础能力。本轮不新增分析模块。

软件版本：`0.3.2`（只改 `APP_INFO.version`）  
工程格式：`projectFormatVersion: "1.0"`（未升格式版本）

## 如何运行

仓库根目录用 Chrome 或 Edge 打开 `temperature_trajectory_visualizer.html`，同目录需要 `visualizer-core.js`。开发调试可执行 `python3 -m http.server`。核心测试：`node tests/core-test.js`。

## 已完成

- Detail Figure：框选后「创建局部视图」生成 `type: "detail"` 的普通 Figure。X 使用框选范围；Y 按该区间内可见曲线重新计算，默认上下各留 5% 数据跨度。局部图有独立范围、轴、标题、图例、尺寸、位置、系列覆盖和标注，不回写父图，父图后续改样式也不覆盖局部图。默认放在来源图右侧；右侧放不下时改放到画布内，避免整张局部图落在画布外面。
- Source Region：父图按数据坐标画来源框。连接线从朝向局部图的一边连到局部图外缘。可关显示、改颜色、线宽、线型。导出 SVG 包含来源框和连接线。
- 坐标轴四边：Top / Bottom / Left / Right 各自可开关轴线、主刻度、副刻度、刻度标签，刻度可向内或向外。副刻度没有数字。关掉刻度数字或轴标题会释放对应边距。上、右边是 SVG 轴线，不是 CSS border。旧工程默认只打开下边和左边，避免打开后突然多出封闭框。
- 标题：`name` 是编辑器里的图名；`title` 才画在图上，并可关闭。空标题和「未命名图」都不会画出来，也不占标题高度。
- 图例边框与背景分开。默认不画边框。可以透明底加黑框。
- 布局只从顶部「布局」进入。菜单里的分区只移动当前选中的图。每张图右上角不再有「布局」按钮。快速布局模板仍排当前画布上的图。
- 左栏系列行改为：勾选、最终颜色圆点、单行省略的名称、点数。名称过长时悬停看全文。线型预览不在左栏。
- 数据簇颜色方式：统一颜色，或 Palette。预设含 Auto High Contrast、Okabe-Ito、Tol Bright、Tol Muted、ColorBrewer Set1、ColorBrewer Dark2、Tableau 10。高对比色在 OKLab 里用贪心最远点选出 32 色。系列覆盖的颜色不会被换 Palette 冲掉。左栏圆点、曲线、图例、游标标记共用 `resolveSeriesStyle`。
- 读数：点击吸附到离指针最近的可见曲线的真实采样 X，并在各可见曲线的对应点画圆点。靠近的那条曲线标记更大，读数行高亮并滚进可见区。读数面板最高约 300px，超出后内部滚动。游标不进工程、不进导出。
- 标注只新建两种：数据点标注（`seriesId` + 数据坐标锚点 + 引线 + 可拖文本框）和自由文本（Plot Area 归一化坐标，随图移动和缩放）。选中后可拖、可改字、Delete / Backspace 删除。Esc 回到选择。放好一个标注后退出标注模式。

## 兼容性

旧工程缺新字段时由 loader 补默认值。`v0.1.0`～`v0.3.1` 工程仍按格式 `1.0` 打开。缺标题时不写成「未命名图」。缺上边、右边时默认不画。已有标题默认显示。已保存的旧标注类型仍能读出并绘制；新界面只创建数据点标注和自由文本。

## 已知限制

- 连接线是直线，只避免明显穿过局部图中心，不做绕行。局部图在来源图侧下方时，下边那条线会穿过来源图的空白区。
- 上边和右边共用下边、左边的数据范围，不是第二套 Y 轴。
- Auto High Contrast 在 32 色之后按序号循环。
- 最近点仍是线性扫描，支持非单调 X，不为游标单独建索引。
- 读数、悬停高亮、选中蓝框、缩放手柄不进入 PNG / SVG。
- 局部图不复制父图已有标注。
- 本轮在 Cursor 内置 Chromium 里核对了版本号、默认 Figure、工具栏、左栏单行名称、高对比配色、局部图 Y 适配、来源框和顶部布局菜单。没有另开系统 Chrome / Edge，也没有把读数点击和标注拖拽逐项手点完。算法和工程往返由 `node tests/core-test.js` 覆盖。
