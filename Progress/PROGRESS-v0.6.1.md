# Visualizer v0.6.1

## Version Goal

把工作区还给图。Dock 默认不再占高度，进入绘图模式后按当前视口适应图窗，读数框可以直接选曲线。

软件版本：`0.6.1`  
工程格式：`projectFormatVersion: "1.1"`（未改，仍读取 `1.0`）  
文档结构：`schemaVersion: 2`（未升）  
模板格式：`templateFormatVersion: 1`

## 如何运行

用 Chrome 打开仓库根目录的 `temperature_trajectory_visualizer.html`。开发时也可在仓库根目录执行 `python3 -m http.server` 后访问该页。核心测试：`node tests/core-test.js`。

## 已实现

- Dock 默认自动隐藏，浮在页面底部，不占工作区高度。鼠标靠近底边后出现，离开约 300 ms 后收回。图钉可以固定，固定后工作区按实际高度重算。
- 紧凑 Dock 是约 46 px 的图标，名称不常驻。悬停约 280 ms 后在图标上方显示真实图窗预览。展开模式仍是大缩略图。紧凑 / 展开和自动隐藏 / 固定分开记住，键为 `visualizer.workspace.dock`。
- 顶部画布路径和排版 / 绘图放在同一行，高度 48 px。说明改为按需打开。
- 进入绘图模式默认适应窗口。100%、适应窗口、适应宽度分开计算。显示缩放最高 800%，不改图窗毫米尺寸、画布实例位置，也不改导出尺寸。
- 读数框的每一行可以悬停和点击。点中后保持当前 X，只切换关注曲线，不改系列可见性。系列超过 8 条时可以筛选。上下方向键和 Esc 可用。
- 左侧数据簇和系列可以打开概览：点数、范围、单位、均值、缺失值和抽样表。
- 图窗宽高改为毫米数字输入。单栏 89 mm、双栏 183 mm 只改宽度。显示标题、图例、轴标题和轴线类开关改为同一套 Toggle。

## 已验证

- `node tests/core-test.js` 通过。覆盖适应窗口可以大于 1、适应宽度、89 / 183 mm、单双栏不改高度、同名系列按 ID 分开摘要。
- Chrome（Playwright，1440×900）核对：Dock 默认在视口外，底边呼出后高度约 100 px；隐藏时中间滚动区约 699 px，固定后约 579 px。336×227 的图窗进入绘图模式后为 230%，纸面约 774×523。100% 回到 336×227。双栏把宽度改为 692 px、高度保持 227。返回画布后实例仍是原来的 40,40、1280×800。
- 同一浏览器里导入两列 CSV：T2 概览为 3 点、0–20 s、20–50 °C。读数在 X = 10 给出 T1 30 °C、T2 40.25 °C。点击 T1 后 X 不变，两条曲线都仍可见。方向键可以换到 T2。悬停 Dock 图标出现标题为「图窗 1」的 SVG 预览。
- 适应窗口、适应宽度按钮高度为 26 px，文字没有折成两行。

## 已知限制

- 没有在本机打开 Edge。
- 没有用 20 张以上图窗做滚动和预览压力测试。
- 没有走系统保存框做保存后再打开。SVG / PNG 导出路径没有在这一轮重新点选保存。
- 图上没有单独的「显示网格线」开关，这一轮没有新做网格。
- 透明度和视图缩放仍可能使用已有滑块。图窗宽高没有滑块。
- `Updates/更新介绍.html` 和 `Updates/content.json` 已改成 0.6.1。本机没有 weasyprint，PDF 没有重新生成，仍是 0.6.0 的成稿。
