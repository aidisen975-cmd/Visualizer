# Visualizer v0.6.1

## Version Goal

让绘图区把空间留给图：Dock 默认让开，进入绘图时按视口适应窗口，读数和栏宽控件不再干扰已经稳定的图窗。

软件版本：`0.6.1`  
工程格式：`projectFormatVersion: "1.1"`（仍读取 `1.0`）  
文档结构：`schemaVersion: 2`（未升）  
模板格式：`templateFormatVersion: 1`  
已发布的正式包仍是 https://github.com/aidisen975-cmd/Visualizer/releases/tag/v0.6.0 。这一版没有创建 GitHub Release。

## 如何运行

用 Chrome 打开仓库根目录的 `temperature_trajectory_visualizer.html`。开发时也可在仓库根目录执行 `python3 -m http.server` 后访问该页。核心测试：`node tests/core-test.js`。本机没有 Microsoft Edge，也没有 `kami`。

## 已实现

- Dock 默认自动隐藏，不占布局高度。底部 10px 触发条唤出，约 200ms 浮出，离开约 300ms 隐藏。图钉固定后才占高度并重算工作区。固定与密度记在本机。
- 紧凑 Dock 是约 44px 的图标条，名称不常驻。悬停约 300ms 后在上方弹出 280px 预览，带图窗名。展开模式缩略图明显更大。有曲线时图标和预览使用这张图自己的曲线。
- 模式条压成一行，约 48px。帮助改为悬停问号。
- 进入绘图模式默认适应窗口。100%、适应窗口、适应宽度独立。手动缩放不会在布局变化时被拉回。缩放不改实例几何、层级、坐标范围和导出尺寸。
- 读数行可悬停、可点击锁定关注曲线，不改显隐和勾选。指针进入读数框后锁定当前 X。可过滤。
- 左栏数据概览默认折叠：点数、范围、单位、抽样表。抽样标明不是全量。单位来自数据。
- 单栏 89 mm / 双栏 183 mm 用分段选择，切换不改高度。宽高为数字加毫米。显示类开关改为 Toggle。数据勾选仍是 Checkbox。

## 已知限制

- 同一张画布不能放同一图窗的第二个实例。
- 系统保存框这一版没有再核对。
- Edge 未安装，未测。
- 几十个图窗的压力没有做。浏览器里大约 9 个图窗时，展开 Dock 横向滚动且不换行。
- 读数框的上下键、Enter、Esc 没有在浏览器里按键核对。
- 从图标移入预览不关闭、快速滑过不留残留，没有单独计时核对。
- `Updates/更新介绍.pdf` 仍是 0.6.0。本机没有 `kami`，没有重新生成。
