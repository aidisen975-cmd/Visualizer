Visualizer 0.7.3

片段导出更易读：指定列、表头别名与片段内相对时间。
2026-11-06

新功能

  1. 指定列：指定列导出改用独立列表，长列名完整可读，并支持 Shift 与 Cmd/Ctrl 多选、全选和清空。
  2. 表头别名：导出 CSV 时可选原始表头，或使用左侧数据系列重命名后的列名，只改表头不改数据。
  3. 片段相对时间：创建片段时可把相对时间写进片段本身，可作为横轴并随工程保存；导出时若已有该列则不再重复附加。
  4. 连续切段：创建片段界面去掉多余的「继续创建新片段」，连续切段流程更直接。

修复

  1. 指定列：切换导出目标或跨源导出时，指定列索引与表头不再错位。

0.7.2 · 2026-11-02

  1. 画布副本：同一张图放进多张画布时，图例、标题、刻度和标注属于这份副本，不会改到源图。
  2. 布局：布局上方排整张画布，下方把当前图放进指定格子；占住的格子可以换位，不会复制出第二张。
  3. 拖角：拖动图窗角时图一起变化。靠近格子边会出现虚线并铺满；宽或高接近另一张图时吸成同宽或同高。
  4. 图例分行：图例可以按列数手动分行。长图例用搜索和行标记调整，长名称不再把其他项挤开。
  5. 刻度与模板：自动刻度更密，疏密会写进图表模板。保存同名模板时需选择覆盖、另存或取消。
  6. 标注：点标注后可以在数据点上加文字。文字框可以拖开，数据点留在原处，悬停能看到读数。
  7. 片段导出：创建片段后，底部可以直接导出刚保存的那一段；接着做下一段时，导出仍指向上一段。
  8. 画布导出：画布预览、PNG 和 SVG 会带上主图，局部视图和引导线不再把主图弄丢。

0.7.1 · 2026-10-27

  1. 编码：导入 CSV 时自动识别 UTF-8 和 GBK/GB18030，中文表头按原文字显示。
  2. 表头预览：拿不准编码时会先预览表头，确认后再导入。
  3. 快捷公式：可用快捷公式对勾选曲线求总和、平均、最大和最小。
  4. 计算结果：序列统计结果写进 Results 窗口；逐点计算结果成为新的派生曲线。
  5. 数据片段：可按时间、工步、行号或图上拖选切出数据片段，连续创建不会覆盖上一段，并可导出 CSV。
  6. 横轴：每张图可以为每个数据源另选绘图横轴，包括从 0 开始的相对时间，不改原始数据和公式。
  7. Windows 字体：Windows 下中文界面文字改走宋体系统字体回退，不再依赖 Mac 专用字体名。
  8. Windows 清晰度：Windows 下关闭灰阶字体平滑，改用系统默认清晰度。

0.7.0 · 2026-10-26

  1. 公式列：可用公式从已有曲线生成派生数据，原始表格保持不变。
  2. 时间对齐：不同来源的曲线可按时间轴对齐，支持偏移和有效重叠区间。
  3. 误差指标：可对参考数据和预测数据计算平均误差、均方根误差和偏差。
  4. 分析结果：分析结果放在独立窗口里，可导出摘要和逐点表。
  5. 随工程保存：公式、对齐参数和分析记录会随工程一起保存。
  6. 画布计算信息：画布里点中派生数据时，右侧同时显示画布设置和计算信息。
  7. 结果窗口位置：误差结果窗口默认避开左右侧栏，窄窗口下指标改成两列。

0.6.3 · 2026-10-19

  1. 一级图标：属性栏一级菜单全部带 28px 图标，补上图标题、背景与尺寸、导出设置。
  2. 菜单层级：轴线与刻度作为一级，X Axis 和 Y Axis 收到二级。
  3. 顶栏按钮：顶部新建、打开、保存、导入等按钮带上图标。
  4. 属性与图层：属性和图层改成可点的 Tab，图层每一项是独立卡片。
  5. 画布识别：画布里点中的图显示真实图名，图层能区分主图、局部图、引导线和标注。
  6. 窄窗口顶栏：窗口变窄时顶栏收成图标，不把画布挤出屏幕。
