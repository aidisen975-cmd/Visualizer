# Visualizer

当前版本：**0.6.1**  
工程格式：`projectFormatVersion: "1.1"`，仍可打开 `1.0`。文档结构 `schemaVersion: 2`  
上一正式版：[v0.4.1](https://github.com/aidisen975-cmd/Visualizer/releases/tag/v0.4.1)

浏览器本地运行的实验数据可视化工作台，面向科研与工程出图。数据在本机处理，不经过远程服务器，也不需要安装客户端或注册云端账户。Windows 与 macOS 使用同一份文件。

本文只写**当前版本已经能用的能力**。功能增加或收缩时同步改这一份文件，不把规划写成已上线。完整开发过程见 [DEVLOG.md](DEVLOG.md)，当前开发状态见 [Progress/PROGRESS-v0.6.1.md](Progress/PROGRESS-v0.6.1.md)。这一版能看到的变化写在 [Updates/更新介绍 PDF](Updates/更新介绍.pdf)。

## 特色

- **打开即用**：解压后用 Chrome 打开 HTML，无需安装、无需联网即可导入、绘图和导出。
- **工程可带走**：保存为自包含 `.tvproj.json`，原始数据与排图状态都写进文件。原 CSV 移动或删除后仍可打开；同一工程可在 Windows 与 macOS 之间继续编辑。
- **文件不是图**：Dataset、Series、Plot、Canvas 分开。一张图可以叠多个数据源的曲线；跨文件同名列不会互相覆盖。每条曲线保留独立横纵坐标，不强制共用同一时间轴。
- **画布即导出区**：预览、PNG、SVG 使用当前画布内容和布局，不另做一套导出版式。
- **通用数值 CSV**：不限于温度表。能解析 `Name(unit)`、`Name [unit]`、`Name / unit` 表头，不猜测未写出的单位。
- **出图可控**：多图排版、磁吸对齐、图例位置、曲线与文字样式、坐标轴刻度都可以直接改，适合整理论文和汇报图。

## 功能（v0.6.1）

### 数据导入与管理

- 导入通用数值 CSV；纯文本列会跳过并提示，不导致整表失败。
- 数据按数据源分成数据簇，可折叠 / 展开。左栏只负责导入、浏览和选择：勾选、颜色圆点、单行名称、点数、已选数量、全选、全不选、Shift 连选、Ctrl/Cmd 点选、Ctrl/Cmd+A。名称过长时单行省略，悬停显示全文。成功加入当前图、导入新文件或切换当前图之后，临时勾选会清空；已经画在图里的曲线还在。
- 颜色、线型、线宽在右侧当前图里设置。左栏圆点显示这条曲线当前的最终颜色。右栏按数据簇收起显示「已加入 x/y」，展开后只列出已经加入这张图的系列。数据簇可以统一成一种颜色，也可以按 Palette 给每条曲线分配不同颜色。预设包括 Auto High Contrast、Okabe-Ito、Tol Bright、Tol Muted、ColorBrewer Set1、ColorBrewer Dark2、Tableau 10。单条系列的覆盖优先，换 Palette 不会改掉已经单独设置的颜色；「应用到该数据簇全部系列」才会清掉这些覆盖。
- 曲线区分原始列名与显示名。右侧 Series 行分层显示两者，超长名称省略且不撑破面板；支持单条重命名，以及查找替换、前后缀、`T{n}` / `{original}` 批量重命名（应用前可预览）。
- 右侧可单独勾选要编辑的 Series，与图上的显示 / 隐藏分开：改样式或重命名不会误改可见性。

### 绘图与排版

- 打开或新建工程时给出画布 1 和图窗 1，图窗 1 放在画布 1 上。之后用「添加图」或 Dock 的「新建图窗」得到的图窗不会自动堆到当前画布，需要从 Dock 拖进去。
- Dock 默认自动隐藏，不占绘图高度。鼠标移到屏幕底部后，以紧凑图标浮出；悬停图标会在上方显示这张图的预览。可以改成展开的大缩略图，也可以用图钉固定在底部。这些选择记在本机，不写进工程。画布和图窗仍从这里切换、重命名、复制、删除，也可以只导出当前图窗的 PNG / SVG。删除仍被画布使用的图窗时，会先写出那些画布的名字。从画布上删掉一个实例不会删掉图窗本身。
- 排版模式编辑画布上的位置和大小。双击图，或点 Dock 里的图窗，进入绘图模式；再点「排版模式」回到画布，位置还在。同一张图可以放进多张画布：改曲线和样式会一起变，每张画布上的位置和大小各自保留。
- 画布模式下，右侧图层列出这张画布里的图窗实例。点名字只选中，不改变叠放。上移、下移、置顶、置底才会改层级。绘图模式下，图层仍列出当前图窗里的主图和局部视图。局部视图不出现在 Dock。
- 同一画布可放多张图；图可创建、选择、移动、缩放、删除。排版模式的框选可以同时选中多张图。选中多项时，不一致的位置和尺寸显示「混合值」，只有改过的那一项会一起改。也可以左对齐、水平居中、右对齐、顶对齐、垂直居中、底对齐，以及水平等距或垂直等距。点选图、局部图、图例或标注都不会改变叠放顺序。被挡住的图仍可从图层里选中。选中框画在单独的叠层上，不进入导出。锁定后不能在画布上拖动或缩放，仍可以点选并用右侧属性修改。
- 绘图模式的纸面只显示当前图窗及其局部视图。有曲线的图窗，Dock 缩略图能看出这条曲线。
- 布局从顶部「布局」进入，只对当前选中的图做分区吸附；快速模板仍可一次排好当前画布上的图：单图、1:1 左右、1:1 上下、左大右小、左小右大、三等分、一大两小、两小一大、2×2、3×2。分区按画布逻辑尺寸计算。图块右上角没有布局按钮。
- 画布尺寸在右侧单独设置，预设有 16:9、4:3、A4 横向、A4 纵向、单栏 89 mm、双栏 183 mm 和自定义。浏览器窗口和「适应窗口」只改变显示比例，不改画布逻辑尺寸，也不改图在画布上的位置。图窗自己的宽高在绘图模式里改，和画布上这个实例的宽高分开。
- 磁吸对齐：画布边、其他图的边缘与中心、缩放边，以及等间距候选。
- 左、中、右栏可拖动改宽、双击恢复默认宽度、折叠；栏宽写入工程。
- 显示缩放 25% 到 800%，与图表真实尺寸分离。100% 是逻辑尺寸，适应窗口按当前工作区完整放下图窗，适应宽度只对齐宽度。进入绘图模式时默认适应窗口。Ctrl/Cmd + 滚轮、`+` / `-` 改为手动缩放，之后不会被普通刷新拉回去。
- 图窗宽高用毫米数字输入，不使用滑块。单栏 89 mm、双栏 183 mm 只改宽度。拖角缩放与数值输入同步，可锁定宽高比。新建图默认 1280×800。
- 图标题、轴标题、刻度按实际文字尺寸自动留白；字号变大时 Plot Area 内缩，必要时才增大 Figure，避免标题溢出。图标题可显示或关闭，可左对齐、居中或右对齐。关闭标题、清空标题或关掉轴标题后，对应空白会收回。编辑器里的图名（Figure 1、局部图 1）不会在标题关闭时画到图上。

### 图例、样式与坐标轴

- 图例可开关，支持停靠位置、自由拖动、字体、行 / 列、线样与最大宽度。列数显式指定时按列换行。背景和边框分开：可以透明底、白底、加框或不加框，边框可设颜色、线宽和圆角。默认不画边框。背景透明度不影响文字和线样。
- 曲线样式：颜色、线型、线宽 0.5 到 12 px（0.1 步进）、透明度；可批量改线型 / 线宽 / 透明度，多选线宽不同时显示混合态。颜色只在明确设置时覆盖。颜色可以输入或粘贴 HEX。线型菜单用与绘图相同的虚线样式做预览。
- 文字样式：图标题、轴标题、刻度、图例；字体含系统默认、微软雅黑、宋体、Arial、Times New Roman。轴线颜色与宽度可改。
- 轴标题支持自动识别与手动编辑；用户改过的标题不会被后续加曲线覆盖。
- 坐标范围为自动或手动。X 轴自动范围贴齐数据，左侧从 0 开始不加空白；切到手动时预填当前范围。View Range 与框选放大共用这一组范围。
- 每张图有上、下、左、右四条边。每边可单独显示轴线、主刻度、副刻度、刻度数字，刻度可向内或向外。副刻度只有短线。上边和右边默认关闭，打开后与下边、左边共用同一组 X/Y 范围，用来画封闭框图。

### 查看、局部图与标注

- 画布下方工具在同一时刻只有一个：选择、框选、读数、标注。标注里可以选择数据点标注或自由文本。Esc 退出当前工具。
- 在图内框选后可以放大到该范围，或新建一张局部视图。局部视图是来源主图的另一个视窗：曲线、显隐和系列样式实时跟随主图，不单独保存一套样式。X 使用框选或手动范围。Y 有三种模式：跟随主图、按当前 X 窗口里可见曲线自动适配（新建时的默认，边距 5%）、手动范围。自动适配只统计这个 X 窗口内的可见曲线，隐藏曲线不参与；改 X 或边距后 Y 会重算，并真正作为局部图的坐标范围。属性里优先显示当前窗口和 X/Y 跨度，有效放大倍率放在后面。图标题、轴标题、图例默认关闭，需要时可以打开，关闭后对应空白会收回。来源框和引导线跟着这张局部视图，删除局部视图时一起消失。取消或 Esc 只去掉选框。
- 右侧属性跟着当前点中的对象。点主图时仍是图表、X/Y 轴、图例、数据系列、局部视图、标注与引导线、导出设置。点局部图时是它自己的范围、标题、坐标轴、图例、来源框与引导线、位置与尺寸。直接点图例、某条标注、来源框或引导线时，右侧只留下这一项的设置。图例可改显示、位置、行列、字体和背景边框；标注只改这条标注自己的文字或线条；来源框和引导线只改显示、颜色、线宽和线型。Delete 会删除主图、局部图和标注；对图例、来源框和引导线则是隐藏。Esc 先取消正在进行的拖动或创建，否则只取消选中。双击图标题、轴标题或标注文字会打开对应输入框。同一对象上的展开状态会保留。导出时绘制固定游标在导出设置里。
- 顶部是一行工程工具栏：导入、新建、打开、保存（含另存为）、新建图（含图表模板）、布局、预览、导出（PNG / SVG）和关于。软件名和版本在同一行，不另占标题区。
- 读数吸附到最近的真实采样点，在各可见曲线上画圆点，并列出数值和单位。可以把鼠标移进读数框，点某一行或用上下方向键换关注曲线；当前 X 保持不变，其他曲线不会被隐藏。系列很多时列表内部滚动，并可以按名称筛选。Esc、退出读数或切换图都会去掉它。它不进工程、标注和 PNG/SVG。旧工程里已经存在的固定游标 A/B 仍可清除；勾选「导出时绘制固定游标」后，预览与 PNG/SVG 才包含这些固定游标。
- 左侧数据簇和系列可以打开概览：点数、横纵范围、单位、均值、缺失值和少量抽样。抽样会标明不是全部原始数据。同名列按系列 ID 分开，不会把秒改成分钟，也不会把温度单位套到其他量上。
- 数据点标注吸到真实采样点，保存系列和数据坐标；文本框可拖，引线跟着走，锚点不离开该点。自由文本按图内相对位置保存，图移动或画布缩放后仍留在这张图里。选中后可改字体、字号、颜色、背景和边框，Delete / Backspace 删除。旧工程里的文字、箭头、标记和区域仍能打开。
- Cmd/Ctrl+Z 撤销，Cmd/Ctrl+Shift+Z 或 Ctrl+Y 重做。移动和缩放在松手时记一条，不会把每个像素都记下来。
- 每张图可独立设置时间显示单位（含 ms）；换算只发生在显示层，不改写原始数据。
- 刻度可自动或手动：主间隔、次刻度、小数位。非法间隔或主刻度超过 500 会被拒绝。

### 图表模板

- 可以把当前主图的绘图格式存成模板：尺寸与背景、标题、X/Y 轴外观、上边和右边、图例，以及新曲线的默认线宽、线型和调色。不保存数据、曲线名单、当前坐标范围、标注和局部视图。
- 「+ 图」使用默认模板；旁边的菜单可以选择系统默认、已有模板、保存当前图、管理模板或导入。管理里可以应用、设为默认、重命名、复制、删除和导出。
- 模板也可以应用到已经画好的图上：样式会变，数据、显隐、坐标范围、标注、局部图关系和画布位置保持不变。已经单独改过的曲线颜色和线宽不会被模板清掉。撤销可以整次退回。
- 模板存在本机浏览器里，并可以导出、导入 `.tvtemplate.json`。删掉模板不会改变已经画好的图，也不会改已保存的工程。局部视图不能存成图表模板。

### 工程、预览与导出

- 新建、打开、保存、另存为工程。
- 浏览器没有系统文件对话框时，保存会下载到默认目录。
- PNG、SVG、另存为走同一套保存逻辑。
- 可打开旧版工程；缺失字段在加载时补默认值，不要求手动升级文件。
- 标题栏「关于」显示当前软件版本和工程格式。两者分开，软件更新不要求升级工程。
- 「检查更新」只在点击后访问 GitHub Releases。可以查看更新说明，并打开对应的 `Visualizer-vX.Y.Z.zip`。没有正式包时改为打开 Release 页面。下载后不会自动覆盖当前文件，需要自行解压并用新版本打开。
- 断网时导入、绘图、保存、打开工程、预览和导出不受影响。检查更新失败只留在关于面板里说明。

## 如何使用

1. 下载 [Visualizer-v0.6.0.zip](https://github.com/aidisen975-cmd/Visualizer/releases/tag/v0.6.0) 并解压，或直接使用本仓库根目录文件。上一正式版是 [v0.4.1](https://github.com/aidisen975-cmd/Visualizer/releases/tag/v0.4.1)。
2. 保持以下文件在**同一文件夹**：
   - `temperature_trajectory_visualizer.html`
   - `visualizer-core.js`
   - `README.md`
3. 用 Chrome 打开 HTML（Windows / macOS 步骤相同）。双击即可，一般不需要本地服务器。
4. 导入 CSV，或打开已有 `.tvproj.json`。
5. 排图后可预览，并导出 PNG / SVG；继续编辑请保存工程。

开发调试也可在仓库根目录执行 `python3 -m http.server` 后访问该页面。核心数据测试：`node tests/core-test.js`。

## 当前限制

- 导出菜单里的「导出画布」包含当前画布上的各图窗。「导出当前图窗」只包含这一张图及其局部视图，不包含同一画布上的其他图。
- 画布缩放只影响编辑视口，不写入导出图像。
- 快速布局模板作用于当前画布上的全部图。分区吸附只移动当前选中的图。
- 等间距吸附会给出对齐，辅助线上暂无间距数值标签。
- 读数游标和编辑高亮不进入预览和导出。旧的固定游标默认也不进入；需要出现在图里时，勾选「导出时绘制固定游标」。
- 局部图的连接线是直线，不绕开其他图。
- 上边和右边不能单独设置另一套数据范围。
- 图例被点中后进入图例设置。曲线显隐用数据系列里的眼睛按钮。
- 窗口过窄时，三栏可能挤压画布。
- 无系统文件对话框的浏览器只能保存到默认下载目录。系统保存框里保存后再打开，这一版还没有核对。
- Edge 这一版还没有在本机打开核对。
- 十余个图窗放在同一张画布上，这一版还没有做压力核对。
- 本机没有所选中文字体时使用 fallback，不会报错。
- 检查更新只打开 GitHub Release 或对应压缩包，不会替换当前已经打开的文件。

## 本版本尚未提供

以下能力仍在后续规划中，当前界面不作为已完成功能使用：复制图、公式列、MAE / RMSE、Results、图拆分、双 Y 轴、轴联动、布局锁定、Heatmap、3D。本工具也不做 Origin 级统计分析、拟合、云同步、模板市场或桌面安装包。图层列表只到主图和局部视图，不把图例、标注和引导线拆成子图层。同一画布不能重复放置同一张图窗。
